#03 有限狀態機 FSM 三段式寫法

💡 概念

有限狀態機（Finite State Machine, FSM）由三部分組成：狀態暫存器（記住現在在哪個狀態）、次態邏輯（根據輸入決定下一個狀態）、輸出邏輯。

三段式寫法把這三部分各寫成一個 always：一個循序、兩個組合。好處是每個區塊職責單一，不容易寫出 latch 或時序錯誤，也最容易對照狀態圖除錯。

本例是 Moore 機（輸出只看狀態）：偵測序列 101，偵測到時 found 拉高一拍（允許重疊）。

🧩 程式碼

module seq101 (
    input  wire clk,
    input  wire rst_n,
    input  wire din,
    output reg  found
);
    localparam S0   = 2'd0,   // 還沒看到任何東西
               S1   = 2'd1,   // 看到 1
               S10  = 2'd2,   // 看到 10
               S101 = 2'd3;   // 看到 101

    reg [1:0] state, next_state;

    // ① 狀態暫存器（循序）
    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) state <= S0;
        else        state <= next_state;
    end

    // ② 次態邏輯（組合）
    always @(*) begin
        next_state = state;           // 預設：留在原狀態
        case (state)
            S0:   next_state = din ? S1   : S0;
            S1:   next_state = din ? S1   : S10;
            S10:  next_state = din ? S101 : S0;
            S101: next_state = din ? S1   : S10;
            default: next_state = S0;
        endcase
    end

    // ③ 輸出邏輯（組合，Moore）
    always @(*) begin
        found = (state == S101);
    end
endmodule

⚠️ 常見錯誤

1. 次態邏輯沒有預設值 → 產生 latch（見 #02）。

always @(*) begin
    case (state)
        S0: if (din) next_state = S1;   // din=0 沒指定
    endcase
end
always @(*) begin
    next_state = state;
    case (state)
        S0: if (din) next_state = S1;
    endcase
end

2. 狀態用魔術數字：state <= 2'd2; 讀不懂也難改。一律用 localparam 命名。

3. 在狀態暫存器 always 裡順便算輸出：輸出會多延遲一拍，和狀態圖對不上。輸出要放在獨立的組合 always。

✅ 重點整理

  • 三段式：狀態暫存器（<=）＋ 次態邏輯（=）＋ 輸出邏輯（=）。
  • 次態邏輯開頭寫 next_state = state; 避免 latch。
  • 狀態用 localparam 命名，case 加 default。
  • Moore 輸出只看 state；Mealy 輸出還會看輸入。
