#01 Blocking vs Non-blocking

💡 概念

Blocking assignment（=）會「立刻」更新左邊的變數，下一行看到的就是新值，行為像一般程式語言。

Non-blocking assignment（<=）則是先把右邊全部算完，等這個時間點的所有敘述都執行完，才「同時」更新左邊。

這正好對應硬體：一排 D 型正反器（D flip-flop）在同一個 clock edge 同時取樣、同時更新。所以規則很簡單：循序邏輯用 <=，組合邏輯用 =。

🧩 程式碼

三級移位暫存器（shift register），每個 clock 把資料往後推一格：

module shift3 (
    input  wire clk,
    input  wire rst_n,
    input  wire d,
    output reg  q3
);
    reg q1, q2;

    always @(posedge clk or negedge rst_n) begin
        if (!rst_n) begin
            q1 <= 1'b0;
            q2 <= 1'b0;
            q3 <= 1'b0;
        end else begin
            q1 <= d;
            q2 <= q1;   // 拿到的是「舊的」q1
            q3 <= q2;   // 拿到的是「舊的」q2
        end
    end
endmodule

🔌 合成後的硬體

三個 DFF 串接，資料需要 3 個 clock 才會從 d 走到 q3：

        ┌────┐     ┌────┐     ┌────┐
  d ───►│ D Q├─q1─►│ D Q├─q2─►│ D Q├───► q3
        │ >  │     │ >  │     │ >  │
        └─┬──┘     └─┬──┘     └─┬──┘
  clk ────┴──────────┴──────────┘

如果把 <= 全換成 =，q1 = d; q2 = q1; q3 = q2; 會在同一瞬間連鎖更新，合成工具只會留下一個 DFF，三個輸出都等於 d 延遲一拍。

⚠️ 常見錯誤

1. 在時序 always 裡用 =：模擬結果會依敘述順序而變，和硬體不符。

always @(posedge clk) begin
    q1 = d;
    q2 = q1;   // q2 會直接變成 d
end
always @(posedge clk) begin
    q1 <= d;
    q2 <= q1;
end

2. 同一個 always 混用 = 與 <=：可讀性差，也容易產生模擬/合成不一致。一個 always 只用一種。

3. 在兩個 always 裡指定同一個 reg：會變成 multiple driver，合成報錯。

always @(posedge clk) cnt <= cnt + 1;
always @(posedge clk) if (clr) cnt <= 0;
always @(posedge clk)
    if (clr) cnt <= 0;
    else     cnt <= cnt + 1;

✅ 重點整理

  • = 立即更新；<= 等這個時間點結束才一起更新。
  • 循序邏輯（posedge clk）一律用 <=。
  • 組合邏輯（always @(*)）一律用 =。
  • 一個 always 只用一種指定方式；一個 reg 只在一個 always 裡被指定。
